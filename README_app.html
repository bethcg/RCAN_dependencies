Probabilistic predictions of recruitment time and subject count based on a Poisson process with a constant recruitment rate over time

Introduction

This Shiny application is a user-friendly, interactive tool that scales recruitment rates which are constant over time and generates probabilistic predictions that account for the inherent stochastic variability of the recruitment process. Users without coding experience or statistical expertise can use it to assess how increasing or decreasing the recruitment rate value by a scaling factor affects predictions of recruitment time and subject counts. Users can interactively change their assumptions to instantly obtain updated plots, estimates, and interpretations. This enables them to efficiently make informed decisions accounting for the stochastic variability of recruitment processes when designing and planning medical studies.


Disclaimer

The predictions provided by this Shiny application are only as reliable as the information given as input by the user. Moreover, they apply only if the recruitment rate is approximately constant over time. The authors of this Shiny application take no responsibility for decisions made using its outputs.

Instructions: Installing the application

Setting up R

To run this application, the free-of-charge R software is required. In addition, five R packages are required: “bslib”, “kableExtra”, “knitR”, “shiny” and “shinyscreenshot”. We also recommend installing RStudio for ease of use.

We recommend installing the software in the following order:

  1. R

  2. RStudio

  3. the five packages using the following command:

install.packages(c("bslib", "kableExtra", "knitr", "shiny", "shinyscreenshot"))


Launching the application

First, extract the files and folders from the downloaded ZIP file.

This app can then be launched and used as follows:

Using RStudio:

  1. Open the file “app.R” in RStudio

  2. Click on the “Run App” button on the top right of the screen


Using the R console:

  1. Set the working directory to the directory in which the file “app.R” is stored

  2. Run the following code

shiny::runApp('./app.R')
  1. Copy the displayed URL and paste it in a browser.


Using the terminal:

  1. Navigate to the directory in which the file “app.R” is stored

  2. Run the following code

R -e "shiny::runApp('./app.R')"
  1. Copy the displayed URL and paste it in a browser.


Warning: After launching the application, a message may appear saying that an updated version of the “shiny” package is needed. In this case, install the updated version.


Terminating the application

Close the window or browser tab in which the application is running.


Instructions: Using the application

Hints for scaling the page

If the app has been launched from RStudio, it will open in a separate RStudio window. To ensure good sizing of the page, click on the “Open in Browser” button in that window. Once the app is displayed in the browser, use the integrated zoom function of the browser to resize the content.


Structure

The application is organised in two main tabs. The “Scaling of recruitment rate” tab enables users to quantify the impact of scaling recruitment rate by a factor \(f\) on the recruitment counts and recruitment time. The factor \(f\) can represent either an administrative action that increases recruitment rate and speeds up recruitment, or in opposition a retention factor that reduces recruitment rate and lengthens the recruitment. The “Converting time units” tab uses the scaling factor \(f\) to convert time units between days, weeks, months, and years. This enables users to shift the time unit of the prediction into their preferred modelling scale.

To model recruitment time and subject count, this application uses a homogeneous Poisson process with a recruitment rate \(\lambda\) which is constant over time (Carter, 2004).


Input

Recruitment rate \(\lambda\): Expected recruitment rate for the planned study = expected subject count per unit of time.

Unit of time: Unit in which the study recruitment is planned (e.g. days, months, years).

Counting unit: Unit in which study subjects are counted in plural form (e.g. participants, patients).

Target count \(\text{C}_{\text{target}}\): Target recruitment count (sample size) of the study.

Target time \(\text{T}_{\text{target}}\): Target recruitment duration of the study in the chosen unit of time.

Scaling factor \(f\) : Factor > 0 by which an intervention increases or reduces recruitment rate. Will be calculated from the scaled recruitment rate \(\lambda_{\text{scaled}}\) if that value is specified.

Scaled recruitment rate \(\lambda_{\text{scaled}}\): Recruitment rate \(\lambda_{\text{scaled}} = f \cdot \lambda\) obtained by applying the scaling factor \(f\) to the original recruitment rate. Will be calculated from the scaling factor \(f\) if that value is specified.


Output

Cumulative recruitment plot: Uncertainty bands for the cumulative subject count recruited over time. The inner band shows central 50% prediction intervals and the outer band central 95% prediction intervals.

Summary: Accessible and non-technical description of results to help interpretation.

Quantiles table: Values of the count at \(\text{T}_{\text{target}}\) and the time to recruit \(\text{C}_{\text{target}}\) subjects, corresponding to fixed probabilities of achieving them.

Distributions: Visualizations of the predictive distribution of the cumulative subject count at time \(\text{T}_{\text{target}}\) and of the predictive distribution of time to recruit \(\text{C}_{\text{target}}\) subjects.

  • For time: Density of the predictive distribution of time to recruit \(\text{C}_{\text{target}}\) subjects.

  • For counts: Probability mass function of the predictive distribution of the count at time \(\text{T}_{\text{target}}\).

Cumulative distributions: Alternative visualization of the predictive distributions of the count at \(\text{T}_{\text{target}}\) and of the time to recruit \(\text{C}_{\text{target}}\) subjects.


Examples

The folder “examples” contains screenshots of the input and output for the 4 examples described in Walker et al. (2026), for both time and count. The values of the expected recruitment rate \(\lambda\), the target subject count \(\text{C}_{\text{target}}\) and the target recruitment duration \(\text{T}_{\text{target}}\) are taken from an example in Carter (2004). These are also set as the default values for these parameters in the Shiny application.

Examples 1-3 illustrate the functionality of the “Scaling of recruitment rates” tab. Examples 1 and 2 focus on administrative actions to increase recruitment rates. Example 3 considers a reduced recruitment rate due to patient leakage during the study duration. Example 4 illustrates the functionality of the “Converting time units” tab. In this example, the time unit is converted from days to months.

We use the following scaling factors \(f\) from the literature in examples 1-3:

Intervention Scaling factor \(f\) Reference
Open-trial rather than blinded 1.1 Treweek et al. (2018)
Telephone reminder to non-respondents 1.06 Treweek et al. (2018)
Retention rate 0.89 Walters et al. (2017)


Extra considerations

Exporting outputs

All outputs can directly be exported to PNG files by pressing the “export” button on the bottom left corner of the pages. Pressing this bottom will generate a screenshot of the displayed tab (only the visible parts on the screen). For further help, see the subsection on scaling the page.

Converting time units while predicting counts

Converting time units while predicting counts has no effect on the probabilistic prediction generated by this application. This is expected behavior as, for example, predicting the count of participants recruited in 2 weeks is equivalent to predicting the number of participants recruited in 14 days.
